# Security

This is a public distribution repository. Commit only plugin material intended
for public access. Keep credentials, private keys, client profiles, customer
data, and generated client reports outside this repository.

Listing a plugin allows users to retrieve its packaged files. Review executable
components, requested authentication, host permissions, and external data
providers before publication. Catalog availability does not establish that a
plugin or a resulting analysis is safe for every use case.

Host-managed connections and credentials remain in the user's environment.
Plugin documentation must describe any required external integration and data
boundary. Apply the relevant canonical InnoLotus security and review standards;
this scaffold does not establish compliance certification.

If reporting a vulnerability, avoid posting exploitable details or credentials
in public issues. Use GitHub private vulnerability reporting when enabled, or
arrange a private channel with the repository maintainers.
